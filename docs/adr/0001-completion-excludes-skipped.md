# Plan completion excludes skipped sessions

Completion วัดความสม่ำเสมอต่อแผนที่ยังยืนอยู่ ไม่ใช่การลงโทษการปรับแผน Skipped คือการตัดสินใจอย่างตั้งใจ (ป่วย ติดธุระ) จึงออกจากตัวหาร ส่วน Missed (เงียบหายไม่บันทึกไม่ข้าม) ยังอยู่ในตัวหาร Partial แสดงแยกโดยไม่มีคะแนน 0.5 ที่ไม่มีที่มา กรณีข้ามทั้งสัปดาห์แสดง “ข้ามทั้งหมด” แทนการหารศูนย์
